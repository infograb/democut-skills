# 사용성 규칙 — 비워 둘 자리와 그 근거

`planner.py` 의 `CAT` 표가 이 값을 쓴다. 값을 바꾸면 이 문서와 코드를 같은 PR 에서 고친다.
`check` 는 **최소**에 못 미치면 오류, **권장**에 못 미치면 주의를 낸다.

## 출처 표기

| 표기 | 뜻 |
|---|---|
| 오늘의집 | [공간별 가구를 배치할 때 생각할 점](https://ohou.se/advices/26) (2016-09-10, 2026-11-09 확인) |
| 커뮤니티 표 | curiositech 의 `interior-design-expert` 스킬 공간 계획 표. 그 표도 원 출처를 적지 않았다. 참고만 한다 |
| IPC | International Plumbing Code 405.3.1 (변기 중심에서 옆 벽까지 15in = 381mm, 앞 21in = 533mm) |
| 판단 | 이 스킬이 정한 기본값. 확인된 출처가 없다 |

## 품목별 값 (mm)

| category | 어디를 비우나 | 최소 | 권장 | 근거 |
|---|---|---|---|---|
| `bed` | 긴 두 변(머리맡 600 은 협탁 자리라 빼고 잰다) | 500 | 650 | 오늘의집: 더블 침대는 양쪽 최소 65cm. 커뮤니티 표: 침대 옆 600. 최소 500 은 판단(좁은 원룸) |
| `wardrobe` 여닫이 | 정면 | 750 | 900 | 오늘의집: 침대와 여닫이 옷장 사이 90cm. 커뮤니티 표: 옷장 앞 최소 750 |
| `wardrobe` + `"door": "sliding"` | 정면 | 500 | 600 | 오늘의집: 미닫이·접이문은 50~60cm |
| `dresser` | 정면(서랍을 빼고 앉는다) | 750 | 900 | 판단(여닫이 옷장과 같게) |
| `bookshelf` · `storage` · `shoe_cabinet` | 정면 | 600 | 750 | 판단 |
| `desk` | 정면 중 폭 700 한 자리(의자) | 750 | 900 | 커뮤니티 표: 책상 의자 자리 900×900 |
| `vanity` | 정면 중 폭 600 한 자리 | 700 | 800 | 판단 |
| `sofa` · `tv_stand` | 정면 | 450 | 600 | 커뮤니티 표: 소파와 거실 테이블 사이 450~500 |
| `dining_table` | 의자 쪽 변(`seat_sides`, 없으면 긴 두 변) | 750 | 900 | 커뮤니티 표: 식탁 의자를 빼는 데 900 |
| `kitchen_counter` | 정면 | 900 | 1100 | 판단(문 연 하부장 + 사람) |
| `fridge` | 정면 | 800 | 1000 | 판단(문 폭 + 사람) |
| `washer` · `dryer` | 정면 | 600 | 800 | 판단 |
| `toilet` | 정면 | 600 | 700 | IPC 앞 533 을 올려 잡았다 |
| `washbasin` | 정면 | 600 | 750 | 판단 |
| `shower` · `bathtub` | 정면 | 600 | 700 | 판단 |
| `appliance` | 정면 | 600 | 750 | 판단 |

빈 자리를 요구하지 않는 품목: `nightstand` · `coffee_table` · `chair` · `lamp` · `plant` · `tv` · `mirror` · `other`.
`rug` 는 바닥에 깔려서 장애물이 아니다.

품목 하나만 다르게 하려면 `"clearance": {"front": [min, rec]}` (침대는 `side`, 식탁은 `seat`)를 준다.

## 품목이 아니라 집에 걸리는 규칙

| 규칙 | 값 | 근거 |
|---|---|---|
| 동선이 끊겼다(오류) | 폭 약 550mm 길로도 못 닿는 가구 | 커뮤니티 표: 비집고 지나가는 폭 450. 검사 격자가 50mm 라 550 으로 잡았다 |
| 동선이 좁아진다(주의) | 약 750mm 길로는 못 가고 550mm 길로만 닿는 넓은 구역 | 커뮤니티 표: 보조 동선 600~900 |
| 문 앞 | 문 폭 × 깊이 500 을 비운다(주의). 폭 1200 이상 트인 개구부는 보지 않는다 | 판단 |
| 문이 열리는 범위 | 여닫이 문 반지름 = 문 폭. 장애물이 걸리면 오류 | 기하 |
| 창 앞 | 창 앞 300 안에 창턱보다 높은 가구가 있으면 주의 | 판단 |
| 벽에 붙이는 품목 | 벽에서 100 넘게 뜨면 주의 | 오늘의집: 침대는 벽에서 10cm 정도 떼면 침구 정리가 쉽다 |
| 문 폭 | 바깥으로 나가는 문 850 미만, 방문 750 미만, 화장실 문 650 미만이면 주의 | 판단. 한국 아파트 방문 900·화장실 문 700~800 은 흔한 값이지만 출처 미확인 |

## 숫자 밖에서 볼 것

- 침대 머리를 창 아래에 두면 창을 여닫기 어렵다. 검사는 창 가림(높이)만 본다.
- 문을 열자마자 침대 발치가 보이는 배치를 피하는 사람이 많다. 취향이라 검사하지 않는다.
- 콘센트 위치는 house.json 에 없다. 사용자가 알려 주면 메모(`meta.notes`)에 적는다.
