# DemoCut Skills

DemoCut 쓰임새 스킬 모음. DemoCut 제품 안에 넣기는 애매하지만, DemoCut 으로 영상을 만들 때
앞뒤로 필요한 일을 Claude Code·Cursor·Codex 같은 에이전트에서 바로 하게 하는 절차와 도구를 담는다.

## 설치

에이전트에게 아래 문장을 그대로 붙여넣으세요.

```
DemoCut 스킬을 설치해줘.
`npx skills add infograb/democut-skills` 를 실행하고, 설치가 끝나면 알려줘.
```

수동 설치는 [`docs/install.md`](docs/install.md) 참조.

## 스킬

| 스킬 | 하는 일 | 쓰임새 |
|---|---|---|
| [`room-set-planner`](room-set-planner/SKILL.md) | 방 크기를 받아 오늘의집 제품으로 방을 꾸민다. 제품 실측대로 놓고 사용성(문 열림·앞 여유·동선)을 검사한 평면도와, 사진·가격·평점이 든 리뷰용 인벤토리를 HTML 한 장으로 만든다. 도면만 담은 SVG 도 함께 나온다 | 숏폼마다 바뀌는 촬영용 방 세트와 그 방의 제품 리뷰 준비 |
| [`room-set-photos`](room-set-photos/SKILL.md) | room-set-planner 로 꾸민 방을 오늘의집 집들이 사진처럼 만든다. 촬영 컷을 계산하고 컷마다 카메라 시점 덩어리 스케치·제품 사진 보드·프롬프트를 만들어 DemoCut AI 이미지 컷으로 생성한다. 대표 컷을 나머지 컷의 레퍼런스로 넣어 컷끼리 같은 방으로 보이게 한다 | 방 세트의 컨셉 사진, 영상에 넣을 방 이미지 |
| [`music-video`](music-video/SKILL.md) | 곡으로 뮤직비디오 콘티를 짜고 DemoCut 으로 만든다. 곡의 BPM·마디·음량을 재서 줄마다 시각을 정하고, 컨셉·의상(룩북)·멤버 파트·트렌드 조사·8카운트 안무·카메라 움직임을 콘티 표에 넣는다. 곡을 들려주는 뮤직비디오 컷으로 만들되 입을 맞춰 부르는 줄은 부르는 멤버의 단독샷으로 만들고, 만든 영상을 격자 한 장으로 재서 자른다 | 아이돌·밴드 MV, 곡에 맞춘 숏폼 챌린지 영상 |

## 이 모음이 다루지 않는 것

- **DemoCut 안에서 하는 일** — 컷 만들기·음성·자막·완성본·발행은 DemoCut MCP 도구가 한다.
  이 모음의 스킬은 그 앞뒤(소재 준비, 세트 설계)를 맡는다.
- **구매** — 스킬은 제품을 고르고 정리할 뿐 사지 않는다.

## 왜 스킬인가

에이전트에게 「방 꾸며줘」 라고만 하면 그럴듯한 그림은 나오지만, 제품 치수를 짐작하고
옷장 문이 침대에 걸리는 배치를 내놓는다. 이 모음의 스킬은 실제로 해 보고 확인한 절차를 담고,
눈대중으로 판단하기 어려운 부분(치수 검사, 동선)은 스크립트가 맡는다.

## 개발

```bash
npm run lint    # 스킬 구조 검증 + 스크립트 문법 검사
```
