# 스타일 프로파일을 채우는 법

[templates/style-profile.md](../templates/style-profile.md) 의 칸을 이 순서로 채운다.
숫자는 `posts.json` 에 있는 것만 쓴다. 칸마다 글 id 를 붙이거나 「미확인」이라고 적는다.

프로파일의 본문은 **중앙값보다 높은 글**이다. 중앙값 이하의 글은 「상위와 다른 점」 한 줄에만 쓴다.
같은 특징이 상위 글 두 개 이상에 있을 때만 패턴이다. 하나뿐이면 그 글의 특징으로 적고 포맷의 근거로 쓰지 않는다.

작성자가 둘이면 프로파일도 둘로 나눈다. 포맷의 기준은 사용자가 고른 주 레퍼런스다.

## 메타데이터만으로 확정할 수 있는 것

- 글 수, 기간(`upload_date` 의 처음과 끝), 수집 시각(`collected_at`)
- 조회수 중앙값, 75퍼센트 값, 상위 id, 배수(`views_over_median`)
- 길이 중앙값. 상위의 길이와 전체 길이 중앙값이 다르면 둘 다 적는다
- 제목·캡션의 훅 유형: 질문, 숫자, 제품명으로 시작, 반전, 고민. 문장을 그대로 옮기되 프로파일 안에 「원문」이라고 표시한다. 포맷의 훅 예로 재사용하지 않는다
- 자막 파일의 첫 3초·6초 대사(`cues` 출력). 자동 자막이면 그렇게 표시한다
- 해시태그 중 상위 글에서 반복된 것
- 주소·가로세로로 판정된 `is_short_form`. `null` 이면 세로인지 미확인

## 화면을 봐야 하는 것

아래는 썸네일 한 장, 제목, 길이만으로 확정하지 않는다.

- 컷 수와 컷 길이
- 샷: 셀카, 손으로 든 카메라, 세워 둔 폰, 손 POV, 탑다운, 공식 사진
- 조명
- 화면 글의 위치·줄 수·스타일
- 제품이 처음 나오는 초, 제품을 보여주는 방식
- 엔딩의 화면
- 말의 빠르기, 방 소리, 음악이 말을 덮는지

근거로 쓸 수 있는 것은 세 가지다. 사용자가 본 초 단위 메모, `frames` 로 뽑아 직접 본 키프레임, 자막 시각과 맞는 화면 전환을 사용자가 확인해 준 것.
키프레임을 안 뽑았으면 그 칸은 미확인이다. 「보통 2초에 한 번 자른다」처럼 다른 글의 통념으로 채우지 않는다.

## 칸별 규칙

**훅.** 첫 문장이 제품·숫자·질문·고민·반전 중 무엇인지 상위 글마다 적고, 두 번 이상 나온 유형만 패턴으로 올린다.
3초·6초는 자막 시각이 있을 때만 「N초까지 이 말이 나온다」고 쓴다. 자막이 없으면 미확인.

**길이와 속도.** 상위 글 `duration_s` 의 중앙값을 포맷 길이의 기준으로 적는다.
컷 속도는 화면 근거가 있을 때만 초 단위로 적는다.

**샷.** 단어는 이 여섯 개만 쓴다. 셀카(본인이 한 팔로 든 화면), 핸드헬드(다른 사람이나 양손으로 든 화면), 세워 둔 폰, 손 POV, 탑다운, 공식 사진.
레퍼런스에서 이름이 안 붙는 화면은 한 줄로 설명하고 새 이름을 만들지 않는다.

**조명.** 「창 옆」처럼 원인을 적을 수 있을 때만 적는다. 예쁜 조명 형용사는 쓰지 않는다.

**화면 글.** 줄 수, 화면의 위·가운데·아래, 말과 같은지 다른지. 상위 글 글자 크기의 픽셀 값은 재지 않았으면 적지 않는다.

**말.** 문장 길이, 말을 놓는 시점(혼잣말인지 카메라인지), 반복되는 어미. 유행어와 고유 대사는 「가져오지 않음」에 원문만 적는다.

**구조.** 상위 글에서 반복된 순서만 적는다. 예: 고민 → 제품 전체 → 사용 동작 → 한 줄 반응 → 끝.
한 글의 순서는 구조가 아니다. 자주 쓰는 골격 이름은 [format-design.md](format-design.md) 에 있다. 그 이름에 맞춰 끼워 맞추지 않는다.

**제품 장면.** 제품이 어떤 동작으로 증명되는지(붓기, 펼치기, 크기 비교, 완성 음식)를 글 id 와 함께 적는다.
맛, 효능, 사용 전후처럼 화면 밖에 있는 주장은 적지 않는다.

**엔딩.** 질문, 다음 행동, 짧은 감상 중 반복된 것. 댓글 유도 문장이 있으면 원문을 프로파일에만 둔다.

**소리.** 말만인지, 음악이 있는지, 제품 소리가 말을 대신하는 구간이 있는지. 못 들었으면 미확인.

**가져오지 않을 것.** 얼굴, 집의 특징, 옷, 로고, 훅 원문, 챌린지 안무. 포맷 단계에서 다시 열 목록이다.

## 표본이 얇을 때

상위 글이 두 개 미만이면 패턴이 없다. 프로파일에 그 사실을 적고 포맷은 만들지 않는다.
사용자가 그래도 초안을 원하면, 포맷 제목에 「초안·반복 부족」을 붙이고 확정이라고 말하지 않는다.
