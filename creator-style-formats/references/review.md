# 포맷 체크리스트

`formats.md` 를 넘기기 전에 복사해 포맷 id 마다 표시한다.
여기에는 고치는 순서를 적지 않는다. 통과 / 고칠 것 / 미확인 만 적는다.

## 1. 데이터가 먼저인가

- [ ] `posts.json` 이 있고, 프로파일의 중앙값·배수·id 가 그 파일과 같은가
- [ ] 조회수가 없던 글을 0 으로 넣어 상위에 올리지 않았는가
- [ ] 글을 받지 못한 오류를 숨기지 않았는가
- [ ] oEmbed 만 있는 표로 프로파일을 확정하지 않았는가

## 2. 프로파일

- [ ] 패턴마다 상위 글 id 가 두 개 이상 있는가. 하나뿐인 특징을 포맷의 근거로 쓰지 않았는가
- [ ] 컷 수, 샷, 조명, 제품이 나오는 초에 화면 근거가 있는가. 없으면 미확인인가
- [ ] 레퍼런스 훅 원문이 포맷의 대사 칸에 들어가지 않았는가
- [ ] 작성자가 둘이면 순위를 섞지 않았는가

## 3. 포맷 파일이 구조만인가

- [ ] `formats.md` 에 수집 명령, 견적, 승인, 업로드 순서가 없는가
- [ ] 컷 초의 합이 적은 길이와 맞는가
- [ ] 길이가 상위 글 길이 중앙값과 사용자가 준 상한 안에 있는가
- [ ] 샷 이름이 셀카, 핸드헬드, 세워 둔 폰, 손 POV, 탑다운, 공식 사진 안에서 쓰는가

## 4. 가상 인물

- [ ] 인물이 보이는 컷마다 가까이 「가상인물」이 계속 있는가
- [ ] 글자가 배경과 구분되고, 끝 프레임까지 읽을 수 있는가
- [ ] 먹어 봤다, 써 봤다, 샀다, 본인의 전후, 한 입 반응이 없는가
- [ ] 후기 문장은 전언이고, 출처를 못 찾은 숫자를 만들지 않았는가
- [ ] 돈·협찬·제휴 링크가 있을 때만 광고 표시가 있고, 없을 때 `#광고` 를 만들지 않았는가
- [ ] 레퍼런스의 얼굴, 집, 유행어, 로고를 타깃에 붙이지 않았는가
- [ ] 타깃 프로필에 없는 장소·말투·금지 표현을 다른 캐릭터 예시에서 가져오지 않았는가

## 5. 제품과 음식

제품 컷이 있는 포맷만 본다. 제품이 없으면 이 절은 해당 없음이다.

- [ ] 제품 전체가 가운데에 있고, 9:16 에 맞게 잘리지 않는가. 확대 끝 프레임에서도 그런가
- [ ] 합성 누끼, 오려 붙인 조각, 글자만 자른 상세 컷이 없는가
- [ ] 같은 사진이 바로 다음 컷에 다시 나오지 않는가
- [ ] 사진이 세 장 이상 이어지지 않는가
- [ ] 먹거리면 김·붓기·가르기·소리·탑뷰 중 하나를 골랐고, 음식 전체가 보이는가
- [ ] 단면 확대 하나로 끝나지 않는가
- [ ] 광고·소개·리뷰인데 「좋다」는 말만 있고 제품이 일하는 장면이 없는 포맷이 없는가
- [ ] 패키지를 드는 컷이면 라벨이 카메라를 보고 컷 동안 돌지 않는다고 적혀 있는가

## 6. 말과 끝

- [ ] 훅 예가 새로 쓴 문장인가. 광고·소개·리뷰면 제품명이 첫 3초에 있는가
- [ ] 말의 자리가 타깃 프로필의 말투 안에 있는가
- [ ] 엔딩이 프로필과 맞고, 가짜 희소성이나 숨은 댓글 암호가 없는가
- [ ] 소리 칸이 취향 카드와 같고, 카드가 미확인이면 포맷도 미확인인가

## 7. 취향 카드와 맞는가

- [ ] 확인된 취향 카드가 포맷보다 먼저 있고, 사용자에게 한 장으로 한 번 보여 줬는가
- [ ] 사용자가 말한 한두 단어만 고쳤는가. 카드에 없는 무드·색을 포맷이 더 넣지 않았는가
- [ ] 컷마다 프롬프트 칸에 무드·색감·구성·배치가 있는가
- [ ] 목적에서 더 보기로 한 것이 포맷에 있는가. 댄스면 인물 크기·박자·카메라, 광고면 제품이 나오는 방식
- [ ] 카드의 미확인을 포맷에서 확정값으로 바꾸지 않았는가
- [ ] 댄스·일상·정보인데 제품 증명 장면을 만들어 넣지 않았는가
