# Seedance 모델 카탈로그

2026-08-21 BytePlus ModelArk 모델 리스트 기준. 값이 바뀌면 이 표부터 갱신한다.

| 모델 ID | duration | 해상도 | 특성 |
|---|---|---|---|
| `dreamina-seedance-2-0-260128` | 4~15초 | 480p·720p·1080p(8bit), **4K**(10bit) | 기본. 최대 해상도가 가장 높다 |
| `dreamina-seedance-2-0-fast-260128` | 4~15초 | 480p·720p | 빠르고 저렴 |
| `dreamina-seedance-2-0-mini-260615` | 4~15초 | 480p·720p | 가장 저렴. **테스트용 기본값** |
| `dreamina-seedance-2-5-260628` | **4~30초** | 480p·720p·**1080p(10bit)** | 길이 2배, 1080p 색심도 우위, .mov 출력 |

기능 세트는 4종 공통이다 — Multimodal reference-to-video, Reference-to-video,
Video editing, Video extension, Image-to-video(첫 프레임 / 첫·끝 프레임), Text-to-video.

## 2.5 가 2.0 의 상위 호환은 아니다

버전 번호만 보면 2.5 가 위 같지만 트레이드오프가 있다.

- **최대 해상도는 2.0 이 높다** — 2.0 은 4K(10bit)까지, 2.5 는 1080p 가 상한
- **1080p 품질은 2.5 가 위** — 2.5 의 1080p 는 10bit, 2.0 의 1080p 는 8bit
- **길이는 2.5 가 두 배** — 4~30초 vs 4~15초
- **토큰 단가는 2.5 가 약 1.5배 비싸다**

1080p 이하에서 길이 제약이 없다면 **2.0 + 리소스 팩이 비용 대비 유리하다.**

## 선택 기준

| 상황 | 권장 |
|---|---|
| 파이프라인 검증·프롬프트 실험 | `mini` 720p |
| 일반 제작 | `2-0` 720p~1080p |
| 15초를 넘는 한 컷 | `2-5` |
| 4K 필요 | `2-0` (2.5 는 불가) |

## 공통 파라미터

| 필드 | 값 |
|---|---|
| `ratio` | `16:9` `9:16` `1:1` `4:3` `21:9` `adaptive` |
| `resolution` | `480p` `720p` `1080p` `4k`(2.0 한정) |
| `duration` | 모델별 범위. **범위 밖은 4xx** |
| `watermark` | `false` 로 워터마크 제거 가능 |
| `generate_audio` | 기본 `true`. DemoCut 은 TTS 를 따로 mux 하므로 **`false` 권장** |
| `seed` | 재현성. 응답에도 반환되므로 기록해 두면 같은 결과를 다시 얻을 수 있다 |

프레임레이트는 24fps 고정이다.
