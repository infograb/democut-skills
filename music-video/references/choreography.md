# 안무

안무는 곡에 맞춘다. 박자(언제 움직이나), 구간 에너지(얼마나 크게), 가사(무엇을 하나) 셋이다.
콘티의 안무 칸에 적은 문장이 영상 프롬프트의 안무 문장이 된다.

## 세는 법

- 8카운트 = 8박 = 4/4 박자 두 마디다. 120 BPM 이면 4초, 130 BPM 이면 3.69초.
- 콘티 한 줄(4마디)은 8카운트 둘이다. 안무 칸은 「첫 8박에는 …, 다음 8박은 …」으로 나눠 적는다.
- 한 동작은 1박이나 2박을 쓴다. 한 박에 동작 둘을 넣지 않는다. 사람 눈에도 빠르고, 영상 모델이 따라 그리는지도
  미확인이다(경험칙).

## 가사에서 동작으로

가사 줄마다 동작 하나를 붙인다. 낱말을 몸으로 옮기면 기억에 남는다.

| 가사의 성격 | 동작으로 옮기는 법 | 예 |
|---|---|---|
| 동사(쥐다·돌리다·녹다·켜다) | 그 동작을 손이나 몸으로 그대로 | 「녹아내려」 머리부터 무릎까지 웨이브로 내려간다 |
| 나·너를 가리키는 말 | 가리키기(엄지로 자신, 검지로 카메라) | 「이제 내 차례야」 엄지로 자신을 가리키며 한 걸음 |
| 숫자·카운트 | 손가락을 펴고 한 박에 하나씩 접는다 | 「three, two, one」 |
| 곡 제목·후렴 구호 | 포인트 동작(아래) | |
| 감정·분위기 말 | 표정과 상체(윙크, 고개 기울이기, 어깨 바운스) | |

### 포인트 동작

후렴의 제목 구호에 붙는 동작 하나를 정하고 **후렴마다 되풀이한다**. 인트로에서 작게 미리 보여 주고, 1절 후렴에서
처음 크게 하고, 2절 후렴에서는 하체(점프·런지)를 더해 더 크게 하고, 아웃트로에서 다시 작게 맺는다. 같은 모티프가
커지는 것이 곡의 기승전결이다.

## 구간 에너지와 동작 크기

`mv_timing.py energy` 로 잰 음량이 동작 크기를 정한다.

| 구간 | 동작 |
|---|---|
| 인트로(비트가 가벼우면) | 손과 상체 위주로 작고 정확하게. 비트가 크게 들어오는 박을 기다리는 자세로 끝낸다 |
| 벌스 | 군무 없이 파트 멤버의 걸음·손짓·시선. 나머지 멤버는 화면 밖이나 뒤에서 작게 |
| 프리코러스 | 대형을 모으며 점점 크게. 마지막 박에 멈춤 |
| 후렴 | 전원 같은 동작(유니즌). 포인트 동작 |
| 2절 후렴·마지막 후렴 | 하체까지 크게(점프, 사이드 런지, 바닥까지 내려가는 웨이브), 대형 이동 |
| 소리 빈 자리 | 점프 정점에서 멈추거나 포즈로 정지 |
| 아웃트로 | 인트로 동작을 되풀이하며 한 명씩 맺는다 |

## 챌린지 구간

숏폼에서 따라 하게 할 구간 하나를 정한다(대개 후렴의 한 줄, 15초 안).

- 상체와 손만 쓴다. 세로(9:16)로 가운데를 잘라도 멤버가 다 들어온다.
- 8카운트 하나를 정하고 다음 8카운트는 좌우를 바꿔 되풀이한다.
- 카메라는 정면 고정 풀숏(따라 하는 사람이 보고 배우는 각도).
- 동작마다 가사 낱말과 짝이 있다(따라 부르며 따라 한다).

## 영상 프롬프트로 옮기기

안무 칸을 영어로 옮길 때는 이 순서로 적는다.

1. 대형과 자리: `the three members stand in a V formation, CENTER slightly in front`
2. 박에 맞춘다는 말: `dancing in unison, every move lands on the beat of the attached music`
3. 가사 줄 순서대로 동작: `first line 'Spin it': both hands circle above the head; 'light it up': palms open upward; …`
4. 동작 크기: `small, cute upper-body and hand moves because the intro beat is light`
5. 끝 자세: `on the final beat a knee bend into a crouch, ready for the beat drop`

가사 줄이 영어가 아니면 가사를 따옴표로 넣지 말고 「second line」처럼 차례로 부른다. 입모양은 `CENTER lip-syncs the
last line` 같은 문장으로 맞지 않았다. 입을 맞추는 줄은 [`democut-mv.md`](democut-mv.md) 「입을 맞춰 부르는 컷」대로
만들고, 춤만 추는 줄은 `nobody sings, every mouth stays closed` 처럼 입을 다문다고 적는다.

모델이 동작을 차례대로 다 그리는지는 미확인이다. 만든 뒤 `mv_timing.py sheet` 로 동작 순서와 박을 확인하고,
빠진 동작이 많으면 동작 수를 줄여 다시 만든다.
